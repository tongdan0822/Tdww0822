# 急诊抢救护理记录多端同步系统 - 部署使用说明

## 系统概述

这是一个支持多端数据同步的急诊抢救护理记录系统，包含：
- **Web端**：电脑浏览器、手机浏览器均可使用，响应式设计
- **安卓APP**：支持账号登录，云端数据同步
- **后端服务**：Node.js + SQLite，轻量级，无需单独安装数据库

## 功能特点

- ✅ **账号密码登录**：多用户独立数据，安全可靠
- ✅ **多端数据同步**：手机APP、电脑网页、手机网页，登录同一账号即可查看相同数据
- ✅ **完整填报功能**：完全实现急诊抢救护理记录表格所有字段
- ✅ **一键打印报表**：支持单条记录打印和全部记录汇总打印
- ✅ **数据本地存储**：SQLite数据库，数据文件自动备份
- ✅ **响应式设计**：电脑、平板、手机均可完美使用

## 快速部署（5分钟搞定）

### 环境要求
- 电脑一台（Windows/Mac/Linux均可）
- Node.js 14.0及以上版本

### 第一步：安装Node.js
1. 访问 https://nodejs.org/ 下载LTS版本
2. 双击安装，一路下一步即可
3. 安装完成后，打开命令行输入 `node -v`，显示版本号即安装成功

### 第二步：启动服务
1. 解压 `emergency-nursing-sync.zip` 到任意目录（如 `D:\emergency-nursing-sync`）
2. 进入 `server` 目录
3. **Windows用户**：双击 `start.bat`（如果有），或在地址栏输入 `cmd` 回车，然后执行：
   ```
   npm install
   node server.js
   ```
4. **Mac/Linux用户**：打开终端，进入server目录，执行：
   ```
   npm install
   node server.js
   ```
5. 看到以下提示即启动成功：
   ```
   ========================================
     急诊抢救护理记录多端同步服务已启动
   ========================================
     本地访问: http://localhost:3000
   ```

### 第三步：访问使用
1. **本机使用**：打开浏览器访问 http://localhost:3000
2. **局域网使用**：查看电脑IP地址（Windows输入 `ipconfig`，Mac/Linux输入 `ifconfig`），然后其他设备访问 `http://你的IP:3000`
3. **首次使用**：点击「注册」创建账号，然后登录即可使用

## 多端同步使用方法

### 电脑网页端
1. 确保服务已启动
2. 浏览器访问 http://localhost:3000（本机）或 http://电脑IP:3000（局域网）
3. 登录账号，所有数据自动同步

### 手机网页端
1. 手机和电脑连接同一个WiFi
2. 手机浏览器访问 http://电脑IP:3000
3. 登录账号，数据与电脑端完全同步
4. 可添加到手机桌面，像APP一样使用

### 安卓APP端
1. 安装 `急诊抢救护理记录-同步版.apk`
2. 首次打开设置服务器地址：http://电脑IP:3000
3. 登录账号，数据自动同步到云端
4. 所有设备登录同一账号，数据实时同步

## 一键打印功能

### 打印单条记录
1. 在记录列表中点击某条记录查看详情
2. 点击详情页右上角「📄 打印」按钮
3. 浏览器弹出打印预览，选择打印机即可打印

### 打印全部记录汇总报表
1. 在记录列表页点击「📄 打印报表」按钮
2. 系统自动生成包含所有记录的汇总报表
3. 浏览器弹出打印预览，选择打印机即可打印

### 打印样式
- 标准A4纸张格式
- 宋体字体，正式医疗文书样式
- 包含患者基本信息、抢救记录表格、转归信息
- 底部留有记录人、核对人签字栏

## 数据安全与备份

### 数据存储位置
- 数据库文件：`data/emergency.db`
- 这是一个SQLite数据库文件，包含所有用户和记录数据

### 数据备份
- 定期复制 `data/emergency.db` 文件到其他位置即可完成备份
- 恢复时将备份文件覆盖回原位置即可

### 数据安全
- 密码使用bcrypt加密存储，无法逆向破解
- JWT令牌认证，有效期30天
- 每个用户数据独立隔离，无法互相访问

## 常见问题

### Q: 手机访问不了电脑上的服务？
A: 请检查：
1. 手机和电脑是否连接同一个WiFi
2. 电脑防火墙是否放行3000端口
3. IP地址是否正确

### Q: 关闭电脑后数据还在吗？
A: 数据保存在电脑的数据库文件中，关闭服务或电脑后数据不会丢失。重新启动服务即可继续使用。

### Q: 可以在外网访问吗？
A: 可以，需要做端口映射或使用内网穿透工具（如花生壳、ngrok等），将3000端口映射到公网。

### Q: 支持多少用户同时使用？
A: 本系统为轻量级设计，支持10-20人同时在线使用，适合科室内部使用。

### Q: 打印时格式不对怎么办？
A: 在浏览器打印预览中，确保：
1. 纸张选择A4
2. 边距选择「默认」或「无」
3. 缩放选择100%
4. 勾选「背景图形」（如果需要打印背景色）

## 技术架构

- **后端**：Node.js + Express + better-sqlite3
- **前端**：原生HTML/CSS/JavaScript，无框架依赖
- **认证**：JWT (JSON Web Token)
- **密码加密**：bcryptjs
- **数据库**：SQLite（文件型，无需单独安装）
- **打印**：浏览器原生打印API，专门优化的打印样式
